# Portfolio Structure

Each project uses the following standard structure:

``text
project-name\
|-- diagrams\
|-- evidence\
|-- scripts\
-- README.md
``

## Folder Purpose

### diagrams

Contains architecture diagrams, process flows, deployment flows, and supporting visuals.

### evidence

Contains redacted screenshots and photographs demonstrating configuration and validation.

### scripts

Contains PowerShell scripts, command files, detection scripts, and other reusable technical content.

### README.md

Contains the detailed project objective, implementation, validation, evidence, limitations, and outcome.

## Evidence Rules

- Use lowercase filenames.
- Use hyphens instead of spaces.
- Number evidence in the order it appears in the project README.
- Redact usernames, email addresses, serial numbers, recovery keys, tenant details, and other sensitive information.
- Do not commit Windows ISO files, third-party installers, or generated IntuneWin packages.
